## 🎨 Color Scheme

### **Admin Panel:**
- Primary: Purple (#8b5cf6)
- Icon: Shield (BsShieldCheck)
- Accent: Purple-500/20 for cards

### **Manager Panel:**
- Primary: Purple (#8b5cf6)
- Departments:
  - HR: Blue (#3b82f6)
  - Project: Green (#22c55e)
  - Marketing: Orange (#f97316)
  - Finance: Green-600 (#16a34a)

### **Employee Panel:**
- Primary: Purple (#8b5cf6)
- Icon: Users/Shield indicator
- Accent: Green indicator for "Employee Panel"

```

```

```
Background: Slight darkening

Cursor: Pointer

```

### **Disabled States:**
```

Cursor: Not-allowed
Colors: Grayed out

## 🚀 Component Hierarchy

```
AppRoutes
├── Admin Routes
│   ├── AdminLayout
│   │   ├── AdminSidebar (Panel label)
│   │   ├── Topbar
│   │   └── Dashboard (PanelCard component)
│   └── Other admin pages
│
├── Manager Routes
│   ├── ManagerLayout
│   │   ├── ManagerSidebar (Department nav)
│   │   ├── Topbar
│   │   └── Department Pages
│   │       ├── HR (DeptCard component)
│   │       ├── ProjectHead (DeptCard component)
│   │       ├── Marketing (DeptCard component)
│   │       ├── Finance (DeptCard component)
│   │       └── CheckReports (Report display with timestamp)
│   └── Other manager pages
│
└── Employee Routes
    ├── EmployeeLayout
    │   ├── EmployeeSidebar (Panel label)
    │   ├── Topbar
    │   └── Employee Pages
    │       ├── DailyReport (Timestamp feature)
    │       ├── MyTasks
    │       ├── Attendance
    │       └── Profile
    └── Other employee pages
```

## 📈 Data Synchronization

```
Employee Submits Report
    ↓ (With timestamp generated)
localStorage["employeeReports"]
    ↓
Manager Panel CheckReports
    ↓ (Reads timestamp)
Display: "Date • Time"
    ↓
Admin Panel Dashboard
    ↓ (Reads timestamp)
View All Reports with Times
