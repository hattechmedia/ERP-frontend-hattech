# 🚀 Quick Start Guide - Three Panel System

## 📖 How to Use the New Three-Panel System

### **For Admins**

1. **Login** with admin credentials
2. **Navigate to** Admin Dashboard (`/admin`)
3. **See the overview:**
   - Three-panel visual showing all panels
   - System statistics (Employees, Projects, Tasks, Reports)
   - Quick access to all monitoring features

4. **Access features:**
   - **Dashboard** - System overview
   - **Employees** - View all employees
   - **Projects** - Monitor all projects
   - **Employee Activity** - Track activities
   - **Bookings** - View calendar
   - **Chat** - Communicate
   - **Profile** - Manage your profile

5. **View data from all departments:**
   - ✅ HR data (via Employee lists)
   - ✅ Project data (via Projects page)
   - ✅ Report data (via Dashboard Reports section)
   - ✅ Finance/Marketing (via Dashboard monitoring)

---

### **For Managers (Department Heads)**

1. **Login** with manager credentials
2. **See the expanded sidebar:**
   - Core Operations (Assign Tasks, Activity, Chat)
   - **Manager Panel** (Expandable department section)

3. **Expand Manager Panel** to access departments:

   **📊 HR Management** (`/manager/hr`)
   - View all employees
   - Check employee status
   - Verify attendance
   - Review HR documents

   **🎯 Project Head** (`/manager/project-head`)
   - Create/manage projects
   - Assign tasks to employees
   - Track project progress
   - Monitor completion status

   **📈 Marketing Operations** (`/manager/marketing`)
   - Manage campaigns
   - Track metrics
   - View engagement stats
   - Plan campaigns

   **💰 Finance Records** (`/manager/finance`)
   - Manage budget
   - Track expenses
   - Monitor revenue
   - Generate reports

4. **Review daily reports:**
   - Go to **Manager panel** → Check Reports
   - See employee reports with timestamps
   - View submission time (Date • Time format)

---

### **For Employees**

1. **Login** with employee credentials
2. **See the Employee Panel sidebar**
   - Execution & Reporting focused
   - Simple, task-oriented interface

3. **Complete daily tasks:**
   - **My Tasks** - View assigned tasks
   - **Daily Report** - Submit work report
   - **Attendance** - View auto-marked attendance
   - **Chat** - Team communication
   - **Profile** - Manage your profile

4. **Submit daily report:**
   - Go to **Daily Report**
   - Write what you accomplished
   - Upload attachment (required)
   - Click "Submit Report"
   - ✅ Timestamp automatically added!

5. **Check report history:**
   - Submitted reports show with timestamp
   - Format: Date • Time (e.g., "01/18/2026 • 3:45:30 PM")

## 🎯 Key Features Overview

### **Feature 1: Three-Panel Separation**
```
┌─────────────┐  ┌──────────────┐  ┌────────────┐
│ Admin Panel │  │ Manager      │  │ Employee   │
│ Monitoring  │  │ Panel        │  │ Execution  │
│ (View-only) │  │ (Operational)│  │ (Tasks)    │
└─────────────┘  └──────────────┘  └────────────┘
```

### **Feature 2: Manager Departments**
Instead of one "Manager" role, four departments:
- 👥 HR Management
- 🎯 Project Head
- 📊 Marketing Operations
- 💰 Finance Records

### **Feature 3: Report Timestamps**
All reports automatically include submission time:
```
Employee submits report
    ↓ (Timestamp auto-added)
Date: 01/18/2026
Time: 3:45:30 PM
    ↓
Manager sees: "01/18/2026 • 3:45:30 PM"
    ↓
Admin sees: All reports with timestamps
```

### **Feature 4: Theme Support**
- ✅ Light Theme (light backgrounds)
- ✅ Dark Theme (dark backgrounds)
- ✅ Both with high contrast
- ✅ Switch anytime

## 🔄 Common Workflows

### **Workflow 1: Employee Submits Report**
```
1. Employee logs in
2. Go to Daily Report
3. Write report (e.g., "Completed API testing")
4. Upload attachment
5. Click Submit
6. ✅ Report saved with timestamp automatically
7. Manager can review with timestamp
8. Admin can view in dashboard
```

### **Workflow 2: Manager Assigns Project**
```
1. Manager logs in
2. Click Manager Panel → Project Head
3. Go to "All Projects"
4. Create new project
5. Go to "Assign Tasks"
6. Select employees
7. Assign tasks
8. Employee receives notification
9. Employee acknowledges
10. Manager tracks progress
```

### **Workflow 3: Manager Verifies Attendance**
```
1. Manager logs in
2. Click Manager Panel → HR Management
3. Go to "Attendance Records"
4. See auto-marked attendance from employees
5. Verify and approve
6. Attendance syncs to Admin
```

### **Workflow 4: Admin Monitors System**
```
1. Admin logs in
2. See Dashboard three-panel overview
3. Click stat cards to see details
4. View all employee reports
5. Monitor project progress
6. Check financial metrics
7. Review marketing campaigns
```

## 🎓 Understanding the Three Panels

### **Admin Panel: "What's happening in the company?"**
- Monitors everything
- View-only access
- Global perspective
- No decision-making
- Example: "How many projects are active?"

### **Manager Panel: "What needs to be done?"**
- Operational level
- Full control of department
- Department perspective
- Decision-making for operations
- Example: "Let me assign this project to John"

### **Employee Panel: "What am I doing?"**
- Execution level
- Personal tasks and reports
- Individual perspective
- Focuses on daily work
- Example: "I completed the API testing today"

## 🆘 Troubleshooting

### **Issue: Can't see Manager Panel departments**
**Solution:** Click the arrow (▼) next to "Manager Panel" to expand

### **Issue: Report timestamp not showing**
**Solution:** Refresh the page - timestamp saves automatically with report

### **Issue: Theme not switching**
**Solution:** Look for theme toggle in top-right of Topbar

### **Issue: Route not found**
**Solution:** Check spelling of role in URL (/admin, /manager, /employee)

### **Issue: Can't access page**
**Solution:** Verify you're logged in with correct role
